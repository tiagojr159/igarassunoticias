COMO USAR

1) Extraia este ZIP para a pasta do seu site (ex: /public_html/tiago/ ou /htdocs/tiago/).
2) Estrutura esperada:
   - tiago.php
   - Curriculo_Tiago_Antonio.pdf
   - /images/ (todas as imagens extraídas do PDF)
3) Abra no navegador:
   - http://SEU_DOMINIO/tiago/tiago.php

DICA
- Para editar textos, abra o arquivo tiago.php e ajuste as variáveis no topo.
- Para trocar a foto principal (hero), altere a variável $hero_img no bloco HTML (procure por images/).
